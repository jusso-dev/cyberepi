CyberEpi

API

The machine-readable description is OpenAPI 3.

Sessions use the cyberepi_session cookie from POST /api/v1/auth/login.

  • POST /api/v1/scenarios
  • GET /api/v1/scenarios
  • POST /api/v1/experiments
  • GET /api/v1/experiments/{id}
  • POST /api/v1/experiments/{id}/cancel
  • GET /api/v1/experiments/{id}/results
  • GET /api/v1/pathogens
  • GET /api/v1/controls
  • GET /api/v1/cluster

Propagation stays inside the simulator. Nothing on this API attacks a network.
